# VivaAI – AI Speaking Test & Interview Simulator

## What it does
VivaAI is a web app for English speaking practice with AI-driven evaluation and coaching.
It supports speaking tests, interview simulation, and progress tracking to help users improve communication skills faster.

## Features
- Speaking Test Mode with timed questions
- Interview Mode with recruiter-style feedback
- AI evaluation with IELTS-style scoring dimensions
- Voice input and real-time filler-word hints
- Coaching tips and improved-answer replay
- Local dashboard for strongest/weakest skill trends

## Tech Stack
- PHP (backend)
- Groq API (LLM)
- JavaScript (frontend)
- Web Speech API

## Setup
1. Clone the repository.
2. Create a `.env` file in the project root:
   `GROQ_API_KEY=your_key_here`
3. Run with XAMPP (project under `htdocs/viva-ai`).
4. Open `http://localhost/viva-ai`.
